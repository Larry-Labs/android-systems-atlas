用户确认以高通 Hypervisor 学习线程为素材，按音频专题的图解、术语原位解释、双语和来源规范制作一个独立的“虚拟化与隔离”专题。首版范围固定为 ARM 异常级与虚拟机边界、Guest I/O 的横纵关系、Android AVF/pKVM、Qualcomm QHEE 与 Gunyah 的公开资料语境、IoT 与车载 PVM/GVM 场景。

本专题的 Qualcomm 内容必须分开记录公开证据和教学抽象。QHEE 只按 Qualcomm 安全启动资料中的产品名称及加载链说明；Gunyah 按 Qualcomm Linux 文档和公开源码中的 Type-1 hypervisor 说明。当前资料不足以把所有产品中的 QHEE 写成 Gunyah 的统一历史替代物。车载 PVM/GVM 采用 Qualcomm/Dolby 公开白皮书中的 Physical/Primary VM 与 Guest VM 语境，并在术语中和 Android AVF 的 protected VM（pVM）区分。

本专题主图保持横纵一体。纵向表达 EL0/EL1/EL2/EL3、用户态/内核态/Hypervisor/安全固件的边界，横向表达 Guest 前端、共享内存或 VirtIO、VMM/Resource Manager、宿主后端和设备的协作。数据、控制和返回分别标色与标注，图中动画只表达数据方向，不表示固定时序或性能。没有实际持续数据的关系不添加循环动画。
